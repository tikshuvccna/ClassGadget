ClassGadget היא תוכנה חכמה שנועדה לשדרג את חוויית הלמידה מרחוק (בזום ובפלטפורמות נוספות). המערכת פותחה כ"אולר שוויצרי" למורים, ומאפשרת שליטה חיה בזמן שיעור ללא צורך בהגדרות מורכבות.

## ✨ מה חדש בגרסה 2.0?

* **🎛️ שלט רחוק לזום / Meet / Teams:** לשונית שליטה חדשה עם כפתורים לכל קיצורי המקלדת הנפוצים של Zoom, Google Meet ו-Microsoft Teams — השתק, הפעל וידאו, שתף מסך, צ'אט, ועוד.
* **🎲 גלגל מזל עם מצב "הסר אחרי בחירה":** אפשרות לגרוע שמות שכבר נבחרו כך שכל תלמיד ייבחר פעם אחת בלבד בשיעור.
* **📊 מוני ידני בסקרים:** כפתורי ➕ ➖ לכל אפשרות בסקר, לשיעורים שמתנהלים בצ'אט.
* **💾 שמירה וטעינה של הגדרות שיעור:** שמרו את תור ההודעות, רשימת הסקרים ושמות התלמידים לקובץ JSON כדי לחדש אותם בשיעור הבא.
* **📜 היסטוריית פרומפטים:** שמירה אוטומטית של 5 הפרומפטים האחרונים שנוצרו, עם כפתור לטעינה מהירה.
* **🖼️ תצוגה מקדימה של GIFs:** ריחוף מעל כפתורי GIF מציג תצוגה מקדימה מונפשת של הקובץ לפני ההפעלה.
* **🖱️ גלילת עכבר בכל לשונית:** תמיכה בגלגלת עכבר בכל האזורים הניתנים לגלילה.
* **📂 כפתור פתיחת תיקיית הקלטות:** גישה מהירה לתיקיית ה-recordings ישירות מהלשונית.
* **🔔 התראות לחיצה על צילומי מסך:** הודעות קופצות שפותחות את הקובץ שנשמר בלחיצה.
* **🗜️ כפתור כווץ משופר:** כיווץ ממשק השליטה לשורה אחת בלבד בלחיצה אחת.

## 🛠️ פיצ'רים מרכזיים

* **פופאפים והנפשות:** הקפצת אנימציות (GIF) על גבי המסך בלחיצת כפתור או דרך קיצורי מקלדת (Ctrl+Alt+1 עד 8).
* **כלי מסך מתקדמים:** צילום מסך, חיתוך מדויק, זום חי וציור על המסך (ZoomIt).
* **אפקטים קוליים (SFX) ומוזיקת רקע:** מחיאות כפיים, תופים, שעון מעורר, מוזיקת המתנה ועוד.
* **כלים אינטראקטיביים:** גלגל שמות, סקרים נגררים, מבזק חדשות.
* **משחקי כיתה:** איש תלוי בעברית, אתגרי חשבון, מילה מבולגנת.
* **מחולל פרומפטים (AI):** תבניות מוכנות ליצירת חומרי לימוד בעזרת בינה מלאכותית.
* **מצב Stealth:** הסתרת חלון השליטה משיתוף המסך בזום.
* **אינטגרציה עם ZoomIt:** הגדרה אוטומטית ושליטה בזום/ציור/מצגת חיה.

# ClassGadget v2.0 - Advanced Broadcast Studio for Teachers 🎓🎬

ClassGadget is a smart classroom engagement tool built for Zoom and remote learning. It works as a "Swiss Army knife" for teachers — live control of visuals, sounds, games, polls, and more, all without any complex setup.

## ✨ What's New in v2.0?

* **🎛️ Remote Control Tab:** New tab with one-click hotkey buttons for Zoom, Google Meet, and Microsoft Teams — mute, video, share screen, chat, reactions, and more.
* **🎲 Roulette "Remove After Pick" Mode:** Picked students are removed from the pool so every student gets selected exactly once per lesson.
* **📊 Manual Poll Counters:** ➕ ➖ buttons per poll option — great for lessons run via chat.
* **💾 Session Presets (Save/Load):** Save your message queue, polls, and student list to a JSON file and reload them next lesson.
* **📜 Prompt History:** Last 5 generated AI prompts are saved automatically with a one-click load button.
* **🖼️ GIF Hover Preview:** Hovering over any GIF button shows an animated preview before triggering it on screen.
* **🖱️ Mousewheel Scrolling:** Full scroll support in every scrollable panel.
* **📂 Open Recordings Folder Button:** Direct access to the recordings folder from inside the app.
* **🔔 Clickable Screenshot Notifications:** Tap the notification popup to immediately open the saved file.
* **🗜️ Improved Minimize Button:** Collapses the entire control panel to a single toolbar row with one click.

## 🛠️ Core Features

* **GIF & Animation Popups:** Trigger animated overlays on screen via button or hotkey (Ctrl+Alt+1–8).
* **Screen Tools:** Screenshot, snip, live zoom, and on-screen drawing (ZoomIt integration).
* **Sound Effects & Background Music:** Applause, drums, alarm, hold music, and more.
* **Interactive Tools:** Name roulette wheel, draggable polls, scrolling news ticker.
* **Classroom Games:** Hebrew Hangman, Word Scramble, Math Challenge.
* **AI Prompt Generator:** 12 ready-made Hebrew templates for creating lesson materials with AI.
* **Stealth Mode:** Hide the control window from Zoom screen sharing.
* **ZoomIt Integration:** Auto-configured zoom/draw/live-zoom with no manual setup.

## 📥 Download Options

Everything included, plug and play.
* **Contains:** App, drawing engine, full GIF library, sounds, background music.

## 🚀 How to Install

1. Download your preferred ZIP from the [Releases](../../releases) tab.
2. ⚠️ **Important:** Right-click the ZIP → **"Extract All..."** — do not run the app from inside the ZIP!
3. Open the extracted `ClassGadget` folder and run `ClassGadget.exe`.

> **Tip:** All screenshots and recordings are auto-saved to the `recordings` folder with a date-time stamp.

## ⌨️ Screen Tool Shortcuts

* `Ctrl+Shift+1` → **Zoom In**
* `Ctrl+Shift+2` → **Draw Mode** (freeze screen + free draw)
* `Ctrl+Shift+3` → **Live Zoom** (zoom while mouse stays active)
* `Esc` → Exit any mode
* **Dismiss a popup:** Click once on the GIF/effect overlaid on screen to close it.

## 💡 Adding Your Own Media

* Click **"➕ Upload Image/GIF"** or **"➕ Upload Sound"** inside the app, or
* Drop files directly into the `gifs` folder (PNG, JPG, GIF) or `sounds` folder (MP3, WAV) — the app detects them automatically.
